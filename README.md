# Meal Prep — كتاب تحضير غداء العمل

نسخة تطبيق من الكتاب: افتح الرابط على الهاتف وأضِفه إلى الشاشة الرئيسية، فيفتح بشاشة كاملة وبدون إنترنت.

- آيفون: افتح الرابط في Safari، ثم زر المشاركة، ثم «إضافة إلى الشاشة الرئيسية».
- أندرويد: افتح الرابط في Chrome، ثم ⋮، ثم «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
